# BUG-007 – User can proceed to Checkout with an empty cart

| Field | Details |
|---|---|
| **Bug ID** | BUG-007 |
| **Related Test Case** | TC-024 |
| **Environment** | Google Chrome, Desktop |
| **Test Account** | `standard_user` |
| **Severity** | Medium |
| **Priority** | High |
| **Status** | Open |

## Preconditions

User is logged in as `standard_user` and the shopping cart is empty.

## Steps to Reproduce

1. Verify that no products have been added to the cart.
2. Click the **Cart** icon.
3. Verify that the Cart page is empty.
4. Click **Checkout**.
5. Observe the page displayed after clicking Checkout.

## Expected Result

User should not be able to proceed to Checkout when the shopping cart is empty.

## Actual Result

User is redirected to the Checkout information page despite having no products in the cart.
