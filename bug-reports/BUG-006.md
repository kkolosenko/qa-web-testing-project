# BUG-006 – Application pages load slowly for performance_glitch_user

| Field | Details |
|---|---|
| **Bug ID** | BUG-006 |
| **Related Test Case** | TC-012 |
| **Environment** | Google Chrome, Desktop |
| **Test Account** | `performance_glitch_user` |
| **Severity** | Medium |
| **Priority** | Medium |
| **Status** | Open |

## Preconditions

User is on the SauceDemo Login page.

## Steps to Reproduce

1. Enter `performance_glitch_user` in the Username field.
2. Enter `secret_sauce` in the Password field.
3. Click **Login**.
4. Observe the loading time of the Products page.
5. Open different product details.
6. Navigate between the Products, Cart, and other application pages.
7. Observe page loading behavior.

## Expected Result

Application pages should load consistently within an acceptable response time and navigation should not experience noticeable delays.

## Actual Result

Application pages load noticeably slower than expected, and loading behavior is inconsistent during navigation.
