# BUG-001 – Locked-out user cannot log in despite being listed as an accepted username

| Field | Details |
|---|---|
| Bug ID | BUG-001 |
| Related Test Case | TC-007 |
| Environment | Google Chrome, Desktop |
| Test Account | `locked_out_user` |
| Severity | HIGH |
| Priority | HIGH |
| Status | Open |

## Preconditions

User is on the SauceDemo Login page.

## Steps to Reproduce

1. Enter `locked_out_user` in the Username field.
2. Enter `secret_sauce` in the Password field.
3. Click **Login**.

## Expected Result

User should successfully log in because `locked_out_user` is listed as an accepted username.

## Actual Result

Login is denied and the following error message is displayed:

`Epic sadface: Sorry, this user has been locked out.`
