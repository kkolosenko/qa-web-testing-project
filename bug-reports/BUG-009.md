# BUG-009 – User can proceed to Checkout with invalid customer information

| Field | Details |
|---|---|
| **Bug ID** | BUG-009 |
| **Related Test Case** | TC-055 |
| **Environment** | Google Chrome, Desktop |
| **Test Account** | `standard_user` |
| **Severity** | Medium |
| **Priority** | Medium |
| **Status** | Open |

## Preconditions

User is logged in as `standard_user`, at least one product is in the cart, and the user is on the Checkout information page.

## Steps to Reproduce

1. Enter invalid data in the **First Name** field (e.g. `12345`).
2. Enter invalid data in the **Last Name** field (e.g. `!!!@@@`).
3. Enter invalid data in the **Postal Code** field (e.g. `abcdef`).
4. Click **Continue**.
5. Observe the page displayed after clicking Continue.

## Expected Result

User should not be able to proceed to the Checkout Overview page with invalid customer information. Appropriate validation errors should be displayed.

## Actual Result

User is redirected to the Checkout Overview page despite entering invalid customer information. No validation error is displayed.
