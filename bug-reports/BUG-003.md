# BUG-003 – Incorrect product images are displayed for problem_user

| Field | Details |
|---|---|
| **Bug ID** | BUG-003 |
| **Related Test Case** | TC-009 |
| **Environment** | Google Chrome, Desktop |
| **Test Account** | `problem_user` |
| **Severity** | Medium |
| **Priority** | Medium |
| **Status** | Open |

## Preconditions

User is on the SauceDemo Login page.

## Steps to Reproduce

1. Enter `problem_user` in the Username field.
2. Enter `secret_sauce` in the Password field.
3. Click **Login**.
4. Wait for the Products page to load.
5. Review the product images displayed on the Products page.

## Expected Result

Each product should display the correct image corresponding to the product.

## Actual Result

Incorrect dog images are displayed instead of the corresponding product images for multiple products.
