# Test Plan – SauceDemo Web Application

## 1. Objective
The purpose of this testing is to verify the main functionality of the SauceDemo e-commerce website and identify potential defects.

## 2. Website
https://www.saucedemo.com/

## 3. Scope of Testing
The following functionality will be tested:
- Login
- Product page
- Product sorting
- Shopping cart
- Checkout
- Logout

## 4. Types of Testing
- Functional testing
- UI testing
- Positive testing
- Negative testing
- Cross-browser testing

## 5. Test Environment
- Desktop
- Google Chrome
- Safari

## 6. Test Deliverables
- Test cases
- Bug reports
- Screenshots
